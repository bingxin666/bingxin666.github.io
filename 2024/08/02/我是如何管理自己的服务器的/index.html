我是如何管理自己的云服务器的？

同时拥有多台云服务器，如何管理是好？

好久不见！

最近发现好久没有写博客了，刚刚旅游回来啥都不想写，结果过了好几天才又重新动笔了www。

先简单介绍一下我有的服务器吧：5台位于国内的云服务器，2台位于美国的云服务器，以及位于其他地方的几台云服务器和小鸡。

这个时候，管理这些服务器就成了一件很重要的事情。

0.命名！命名！命名！

给服务器起名字是常常被忽视但也最重要的一步，你可以参考一下我的起名方式。

假设我有一台位于国内的云服务器，配置大于1H1G，是我持有的第五台（位于国内的）服务器，那么我会这样给其命名：

CN-VPS-05

其中，CN 代表 中国大陆 地区，VPS 代表这个是 云服务器，05 代表这是这台服务器在 CN 地区，VPS 范围内的 第五台服务器。

也就是说，我的服务器命名参照以下格式：

国家或地区的代号-类型-编号

这样，无论是哪台服务器，都不会搞混了！

1.统一管理&状态监测

那么，我要怎么记住这么多服务器呢？

这里我可以推荐哪吒面板，几乎就是开箱即用的级别，而且在被控端都可以一键部署。

同时也能做到对于每台服务器的状态监测。

当然，如果你有更深入的需求（例如监测 Docker 实例状态 或者 Web 服务），那么我则推荐Uptime Kuma，能解决绝大多数人的需求了。

2.SSH 连接管理

对于 SSH 连接，我的第一推荐是 Termius，除了免费计划可能功能较少以外，几乎没有任何缺点，而且还能做到全平台同步！

此外，如果你有 Github Students Pack，还可以免费领取 Education 版本！
