让不支持的手机用上中国广电 4G/5G

最近尝试让吃灰的备用机用上中国广电，但是因为广电是这几年才开始发展的运营商，几年前的手机默认都不支持。

但是通过一些神奇的技巧，可以轻松让旧手机用上中国广电 4G/5G。

iPhone 系

让旧 iPhone 用上广电 4G/5G 应该是最简单的了。

需要的工具：爱思助手（或者其他可以刷入 IPCC 文件的工具）

下载中国广电的 IPCC 文件

从以下链接下载并解压出 IPCC 文件：

链接:https://wwxh.lanzoup.com/b00l1nleqd
密码:dd1r

刷入 IPCC 文件

打开爱思助手（或者其他可以刷入 IPCC 文件的工具），连接上你的 iPhone。

打开工具箱 - 更新 IPCC 文件，选择下载的 IPCC 文件，选择一个并且刷入。

随后，如果顺利的话，这时候 iPhone 上左上角应该已经出现了中国广电的非空信号，并且可以正常使用 4G/5G、VoLTE、短信等功能。

如果没有，可以尝试切换至飞行模式一到两次，仍然不工作的话则尝试轮流刷入剩下的 IPCC 文件。

如果顺利的话，打开设置 - 蜂窝移动网络，应该会显示网络选择为中国广电（460-15），且能正常上网。

重启 / 切换网络选择后失效？

开关飞行模式即可。

Android 系

让 Android 系手机用上中国广电是相当灵车的，您可能会遇到以下情况

  • 无法上网
  • 无法发送 / 接收短信
  • 无法使用 VoLTE / VoNR，导致无法拨打 / 接听电话

选择网络

选择网络为中国广电（46015），一般来说会显示已在此网络上注册。

设置 APN 接入点

新建一个接入点，名称和 APN 均填写 cbnet，其他不用管。

随后选择接入点，如果顺利的话就可以正常使用了，如果不顺利的话请按照以下步骤尝试：

手动选择网络

在拨号界面输入 *#*#4636*#*#，选择信息，手动切换网络到 LTE Only 或是 NR / LTE。

如果顺利的话应该可以上网了。

开启 VoLTE

在设置里开启 VoLTE，或是在拨号界面输入 *#*#4636*#*#，选择信息，选择启用 VoLTE。

可能不工作。

结语

总的来说，在旧 iPhone 上使用中国广电的难度约等于零，而在 Android 手机上实现的话难度极大，且很可能只能实现上网。
